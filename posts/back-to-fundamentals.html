Back to Fundamentals

5 Oct 2026 · 1 min read

There's a point in every engineer's career where you can ship almost anything, and that's exactly when the gaps start to show. I can write a query that works. Can I explain why the planner picked that index? Not always.

So this year I went back to school, in my own way. University course lectures on databases and cloud systems, at night, with a notebook, the way I should have the first time.

What changes when you know the layer below

Learning how a database actually stores rows changed how I write migrations. Learning how transactions and isolation levels work changed how I think about two users editing the same invoice. None of it was new information. It was old information I'd been working around instead of understanding.

How I study

  • One course at a time. Finishing one beats starting three.
  • Notes in my own words, right after each lecture.
  • Tie it to work. Every concept gets one example from code I've actually shipped.
The fundamentals don't go out of date. Everything else does.

It's slow, and some weeks I skip it. But every lecture pays back somewhere, usually in a bug I suddenly understand instead of just fixing.
